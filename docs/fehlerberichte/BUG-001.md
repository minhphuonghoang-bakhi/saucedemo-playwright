# BUG-001: Checkout – Eingabe im Feld „Last Name" landet im Feld „First Name"

| | |
|---|---|
| **Gefunden am** | 17.11.2026 |
| **Gefunden von** | Minh Phuong Hoang |
| **Umgebung** | https://www.saucedemo.com · Chromium 131 · Windows 11 |
| **Benutzer** | `problem_user` |
| **Schweregrad** | Kritisch |
| **Priorität** | Hoch |
| **Status** | Offen |
| **Automatisierter Test** | `ProblemUserTest.checkoutWithProblemUser` (`@Disabled` bis zur Behebung) |

## Vorbedingung
- Eingeloggt als `problem_user` / `secret_sauce`
- Mindestens ein Produkt im Warenkorb (z. B. „Sauce Labs Backpack")

## Schritte zur Reproduktion
1. Warenkorb öffnen und auf „Checkout" klicken
2. Im Feld „First Name" `Max` eingeben
3. Im Feld „Last Name" `Mustermann` eingeben
4. Im Feld „Zip/Postal Code" `86150` eingeben
5. Auf „Continue" klicken

## Erwartetes Ergebnis
- „First Name" enthält `Max`, „Last Name" enthält `Mustermann`
- Nach „Continue" wird die Seite „Checkout: Overview" angezeigt

## Tatsächliches Ergebnis
- Die Eingabe aus Schritt 3 erscheint im Feld „First Name"; das Feld „Last Name" bleibt leer
- Nach „Continue" erscheint die Fehlermeldung „Error: Last Name is required"
- Der Benutzer kann **keine Bestellung abschließen**

## Auswirkung
Der Kaufprozess ist für betroffene Benutzer vollständig blockiert (kein Workaround über die Oberfläche).

Trace erzeugen: `@Disabled` in `ProblemUserTest` entfernen und
`mvn test -Dtest=ProblemUserTest` ausführen → `traces/ProblemUserTest_*.zip`
in https://trace.playwright.dev öffnen.

## Hinweise
- Tritt nur mit `problem_user` auf; mit `standard_user` funktioniert der Ablauf (TC-C01).
- Reproduzierbarkeit: 3 von 3 Versuchen.
